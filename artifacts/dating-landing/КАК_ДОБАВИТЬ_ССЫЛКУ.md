# Как добавить партнёрскую ссылку и собрать страницу

## 1. Настройте партнёрскую ссылку и контакты владельца

Откройте файл:

`artifacts/dating-landing/src/config.ts`

Замените пустую строку в `PARTNER_URL` на полный HTTPS-адрес, который выдали в CPA-сети. Вставьте URL целиком, включая партнёрские параметры:

```ts
export const PARTNER_URL = 'https://ссылка-из-партнёрки';
```

Бренд страницы — `Gently Connect`, но это не имя юридического оператора. Перед публикацией укажите в `SITE_OPERATOR_NAME` фактическое имя владельца или его компании и в `HOSTING_PROVIDER` — реальный хостинг и сведения о журналах. Контакт для приватности уже задан в `PRIVACY_CONTACT_EMAIL`; проверьте, что его можно публиковать. Не оставляйте поля с квадратными скобками. Ссылка партнёра должна начинаться с `https://`; пока поле пустое или адрес неверный, кнопка перехода остаётся выключенной.

## 2. Проверьте переход и уведомления

На третьем вопросе кнопка `See your reflection` показывает итог, а `Visit partner dating site` открывает оффер в новой вкладке после подтверждения 18+. Проверьте, что открылся нужный оффер. Внизу страницы доступны политика конфиденциальности, уведомление о cookie и партнёрское раскрытие.

Ответы на вопросы существуют только в памяти открытой страницы: они не отправляются и не сохраняются. На странице нет аналитических и рекламных трекеров. До запуска проверьте в правилах CPA-сети, что прелендинг и выбранный источник трафика разрешены для оффера.

## 3. Сохраните изменения в GitHub

Репозиторий проекта: https://github.com/arteksrab-cmyk/dating_site. Он публичный, поэтому все изменения в исходниках и сама партнёрская ссылка будут доступны посетителям GitHub. Не добавляйте в код API-ключи, пароли или другие секреты. Лучше изменять `config.ts` на своём компьютере, затем отправлять изменения в GitHub; сервер будет получать их через `git pull`.

После изменения проверьте адрес, добавьте и отправьте файл:

```sh
git add artifacts/dating-landing/src/config.ts
git commit -m "Configure partner link"
git push
```

Публичный репозиторий можно клонировать без GitHub-токена. Чтобы собрать и обновить сайт на VPS, выполните команды из корневой инструкции `Инструкция по установке на сервер.md`.

## 4. Соберите статическую версию

Из корневой папки проекта выполните:

```sh
pnpm install --frozen-lockfile
pnpm --filter @workspace/dating-landing run typecheck
PORT=3000 BASE_PATH=/ pnpm --filter @workspace/dating-landing run build
```

Готовые файлы появятся в `artifacts/dating-landing/dist/public/`. На сервер загружается **содержимое** этой папки. Для сайта не нужны база данных или API-сервер; на VPS Nginx раздаёт собранные статические файлы.

Полная пошаговая инструкция по домену, Nginx, DNS и HTTPS находится в файле `Инструкция по установке на сервер.md` в корне проекта.

## Язык страницы

Используется только английский язык, как выбрано для тестового запуска в Индии.
